# Saudi Voice Studio — استوديو الصوت السعودي

استوديو تعليق صوتي عربي/سعودي **مجاني بالكامل ومفتوح المصدر**: واجهة عربية للجوال + خادم MCP + مهارة Claude Code. المحرك: **NAMAA Saudi TTS V2** (نجدي) مع **Habibi‑TTS السعودي** لبقية اللهجات.

> 📱 من جوال Android فقط عبر Colab: [`START-HERE.md`](START-HERE.md) · 🚀 ابدأ من [`START-HERE.md`](START-HERE.md) · 📖 الدليل: [`docs/ARABIC-GUIDE.md`](docs/ARABIC-GUIDE.md)

## الإصدار 1.0.0 (النهائي): صوت جاف + فحص جودة تلقائي + إعدادات الاستوديو
- **لا صدى افتراضيًا** (الصوت جاف ونظيف؛ الصدى فقط بطلب صريح).
- **فحص جودة تلقائي بعد كل توليد** (قصّ، ضجيج، صدى، مستوى، سرعة، وقفات، كلمات ناقصة/مكررة، هوية الراوي) مع إعادة توليد الجمل المشكوك فيها فقط.
- **توحيد سرعة الحديث** بين الجمل، و**إعدادات استوديو** (كلها تلقائية حتى تحرّكها)، تصدير WAV 24-bit وMP3 320k.
- **تسريع bf16 على CPU (2.1× مقيس)**، وقياس ثبات الهوية والنبرة عند إعادة توليد جملة، ومقاطع مشاعر بصوتك (🎭).
- التقرير الصادق بالنتائج والحدود وجدول القبول: [`docs/RELEASE-REPORT.md`](docs/RELEASE-REPORT.md) · التغييرات: [`CHANGELOG.md`](CHANGELOG.md)

## ما الجديد (v5): رواة مبنيون على صوتك + 🔊 استماع + اختيار تلقائي
الرواة صاروا مشتقّين من مقطعك عالي الدقة، مع زر 🔊 لسماع كل راوٍ، وخيار «تلقائي» يختار الراوي من نوع النص — [`docs/NARRATORS.md`](docs/NARRATORS.md).

## ما الجديد (v4): صوتك + زر واحد
ارفع مقطعك مرة واحدة ← اكتب النص ← **✨ ولّد الصوت** (كل شيء تلقائي بأدوات مفتوحة محلية، بلا API ولا حساب). هوية صوتك **مقفولة** (لا تغيير نبرة) وتشابهه مقيس: [`docs/VOICE-MATCH.md`](docs/VOICE-MATCH.md).

## ما الجديد (v3)
1. **إصلاح الشرشرة**: سببها الجذري مقطع مرجعي مشوّش (ضجيج قريب من الكلام ← صوت بلا كلام) وغياب أي فحص. الآن كل مقطع يُفحص ويُعاين قبل الحفظ ويُرفض التالف برسالة — [`docs/REFERENCE-AUDIO.md`](docs/REFERENCE-AUDIO.md).
2. **✨ التحسين الذكي**: فهم دلالي للمعنى + تصحيح النطق والتشكيل السياقي + مشاعر + خطة إلقاء قابلة للمراجعة + مقارنة خام/محسّن — [`docs/SMART-ENHANCEMENT.md`](docs/SMART-ENHANCEMENT.md).
3. الأداء/المحركات/الأرقام: [`docs/PERFORMANCE-ENGINE.md`](docs/PERFORMANCE-ENGINE.md) · [`docs/QUALITY-REPORT.md`](docs/QUALITY-REPORT.md).

## التشغيل السريع (للمتقدمين؛ من الجوال استخدم Colab)
```bash

python -m pytest tests                    # اختبارات سريعة (بلا نماذج)
```

## الأمان والخصوصية
- `SVS_TOKEN` يحمي الواجهة وMCP والتنزيل. لا تنشر الروابط.
- لا تُرفع الأوزان ولا `data/` ولا `voices/refs/*` إلى Git (`.gitignore`).
- استنساخ الصوت يشترط إقرار الحق/الإذن؛ النظام لا يستطيع التحقق منه.
