# ابدأ من هنا 🎙️ (جوال Android فقط)

استوديو تعليق صوتي سعودي **ذكي ومجاني بالكامل**: يحلّل نصك، يقترح خطة إلقاء لكل جملة (مشاعر، سرعة، وقفات، نبرة)، تعدّلها إن شئت، ثم يولّد MP3. **بلا كمبيوتر، بلا دفع، بلا بطاقة.** كل شيء داخل **Google Colab المجاني**.

## زر واحد — الخطوات
1. افتح الدفتر في Chrome على جوالك:
   **<https://colab.research.google.com/github/AliHasan122519/Fakham-MG/blob/ccr-0cfe010a-fw0fdc/saudi-voice-studio/colab/saudi_voice_studio.ipynb>**
   - المستودع **خاص**: سيطلب Colab ربط GitHub (مجاني). البديل: حمّل الملف وارفعه عبر File ← Upload notebook (الدفتر مكتفٍ بذاته).
   - إن ظهرت صفحة مبسطة: قائمة ⋮ ← **موقع سطح المكتب**.
2. (اختياري وأسرع بكثير) **Runtime ← Change runtime type ← T4 GPU**. بدونه يعمل على CPU لكن ببطء (~8× مدة الصوت).
3. اضغط ▶ على الخلية **«تشغيل استوديو الصوت السعودي»** ووافق على إذن Drive.
4. **انتظر ولا تضغط ■**: أول مرة 5–10 دقائق (تنزيل ~8GB مكتبات + ~2.6GB نماذج). يظهر تقدّم وعدّاد كل 15 ثانية.
5. افتح **رابط الواجهة** الذي يظهر.

## داخل الاستوديو (٣ خطوات)
1. **النص**: الصق النص، اختر الشخصية واللهجة والأسلوب، واضبط التحكم (سرعة، درجة التعبير، قوة النبرة، الوقفات، الرسمية، تنويع الإيقاع). اختر **تلقائي** أو **تحكم يدوي**. اضغط «تحليل النص».
2. **الخطة**: لكل جملة: النص المنطوق (عدّله للتشكيل/الأسماء)، العاطفة المكتشفة وسبب اكتشافها، الشدة، وتفاصيل متقدمة (سرعة، نبرة، جهارة، وقفات). اضغط «توليد».
3. **النتيجة**: استمع، بدّل **قبل/بعد التحسين**، قارن النسخ، نزّل **MP3 256kbps** أو WAV، وأعد توليد **جملة واحدة** دون إعادة الباقي.
- **القاموس**: أضف أسماء ومصطلحات وطريقة نطقها. **الشخصيات**: ارفع مقطعًا مرجعيًا (ولكل عاطفة مقطع) لصوت حقيقي خاص بك.

## ما تحتاج أن تعرفه بصدق
- **الصوت يأتي من مقطع مرجعي.** الشخصيات الخمس تعمل الآن بـ **3 مقاطع تجريبية** (مرفقة بحزمة Habibi) + إزاحة هوية/إيقاع/ماستر مختلف لكل شخصية؛ ليست خمسة ممثلين مختلفين. «الراوية» مقطعها تقدير آلي بنطاق نغمة نسائي لم يُتحقق منه سمعيًا. **للتنوع الحقيقي ارفع مقاطعك** (5–10 ث، نظيفة، مع نصها الحرفي).
- **المشاعر**: تشكيل أداء (سرعة/وقفات/جهارة/نبرة) — لا تغيّر جرس الصوت. لجرس عاطفي حقيقي ارفع مقطعًا لكل عاطفة، أو فعّل **المحرك التعبيري** الاختياري (فصحى فقط).
- **الاكتشاف التلقائي** قواعد ومعجم وليس فهمًا للمعنى؛ راجع الخطة. (ومع Claude: اطلب منه تحليل المعنى وتمرير خطة معدّلة.)
- **السرعة**: CPU ~8× مدة الصوت. **اللهجة**: النجدية أصلية، والبقية تقريبية.
- **الترخيص**: أوزان NAMAA/Habibi **غير تجارية** (CC-BY-NC-SA-4.0).

## الربط مع Claude على الجوال (اختياري)
في المخرجات **رابط MCP** (`…/mcp?token=…`): claude.ai ← الإعدادات ← **الموصلات** ← **إضافة موصل مخصص** ← الصقه كاملًا. الرابط يتغير كل تشغيل فحدّث الموصل. أدوات جديدة: `analyze_text` (خطة)، `generate_voiceover`، `regenerate_sentence`، `compare_takes`، `set_pronunciation`. **لم أستطع اختبار الموصل من هنا**؛ إن لم يعمل في خطتك فالواجهة تعمل وحدها.

## الأمان — اقرأها
- **الرابط = مفتاح**: لا تشاركه ولا تحفظ الدفتر «مع المخرجات». الرمز يتجدد كل تشغيل؛ «Disconnect and delete runtime» يبطله فورًا.
- **Drive**: ربطه يعطي البيئة وصولًا لكل Drive (قيد Colab). أزل **USE_GOOGLE_DRIVE** إن أردت (تُعاد التنزيلات كل جلسة).
- cloudflared لا يعمل إلا بعد مطابقة بصمة SHA-256. التفاصيل: `docs/SECURITY-REVIEW.md`.
