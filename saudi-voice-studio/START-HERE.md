# ابدأ من هنا 🎙️

نظام مجاني بالكامل: واجهة عربية + خادم MCP + أصوات سعودية، بنماذج مفتوحة. **صفر ريال، بلا بطاقة، بلا API مدفوع.**

## أين يعمل؟ (اختر واحدًا)

| الخيار | التكلفة | السرعة | متى |
|---|---|---|---|
| **A. جهازك (لابتوب/PC)** | 0 | CPU: ~10× مدة الصوت · GPU: أسرع من الزمن الحقيقي | الأبسط والأكثر ثباتًا |
| **B. Google Colab المجاني** (`colab/saudi_voice_studio.ipynb`) | 0 | GPU T4 عند توفره (غير مضمون) | لا تملك جهازًا قويًا |
| **C. جلسة Claude Code السحابية** | 0 | CPU فقط (جرّبتُ هنا: 4 أنوية، بلا GPU) | تجربة وتطوير |

> ⚠️ لا أحد يضمن GPU مجانيًا دائمًا. إن توقفت الجلسة: أعد تشغيل خلية Colab أو `scripts/start.sh` — النماذج تُحفظ في Drive/القرص فلا تُحمَّل من جديد.

## ثلاث خطوات (الخيار A)

```bash
git clone <مستودعك>  &&  cd saudi-voice-studio
scripts/setup.sh          # بيئة بايثون + المكتبات + نموذج NAMAA (~1.3GB) — مرة واحدة
scripts/start.sh          # يطبع رابط الواجهة ورابط MCP مع رمز سري
```

افتح رابط **الواجهة** في متصفح الجوال أو الحاسوب → اكتب النص → «توليد الصوت» → استمع → نزّل MP3.

## الربط مع Claude على الجوال
1. ثبّت `cloudflared` (مجاني، بلا حساب): <https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/> ثم شغّل `scripts/start.sh` — سيفتح نفقًا HTTPS مجانيًا ويطبع **رابط MCP**.
2. في Claude (claude.ai ← الإعدادات ← الموصلات/Connectors ← إضافة موصل مخصص) الصق رابط MCP كاملًا بما فيه `?token=...`.
3. من جوالك اكتب: «أنشئ لي تعليقًا صوتيًا سعوديًا عميقًا بأسلوب وثائقي، واحفظه MP3» ← يعطيك رابط تنزيل مباشر.

> هذه الخطوة (موصل Claude على الجوال + النفق) **لم أستطع اختبارها من بيئتي**؛ اختبرتُ خادم MCP محليًا بعميل MCP الرسمي. شروط موصلاتك قد تتطلب خطة تدعم الموصلات المخصصة — تحقق من حسابك قبل الاعتماد عليها. إن لم تتوفر، استخدم **الواجهة** مباشرة من متصفح الجوال (نفس الرابط).
