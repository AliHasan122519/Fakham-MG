# الدليل العربي الكامل — استوديو الصوت السعودي

## 0) التشغيل من جوال Android (الطريقة الأساسية)
افتح دفتر Colab (الرابط في `START-HERE.md`) ← اضغط ▶ على «تشغيل استوديو الصوت السعودي» ← افتح رابط الواجهة الذي يظهر. لا أوامر ولا تثبيت. النماذج على Google Drive. تفاصيل: `START-HERE.md`.

## 1) ما الذي يفعله النظام
يحوّل نصًا عربيًا إلى صوت (MP3/WAV) عبر **NAMAA Saudi TTS V2** — نموذج مفتوح مدرَّب على اللهجة النجدية — يعمل على جهازك أو على Colab مجانًا. فيه:
- واجهة ويب عربية للجوال (`/`)
- خادم MCP (`/mcp`) للتحكم من Claude
- روابط تنزيل مباشرة (`/files/<id>.mp3`)
- سجل توليد (SQLite محلي)

## 2) كيف يصنع الصوت (افهمها لتتوقع النتيجة)
النموذج من عائلة F5‑TTS: **يقرأ نصك بنبرة المقطع المرجعي** (5–10 ثوانٍ لمتحدث واحد مع نصه الحرفي). إذن:
- **صوت الشخصية = المقطع المرجعي.** بدونه لا يوجد صوت. الأصوات الخمس الجاهزة تعمل الآن بمقطع تجريبي مرفق بحزمة `habibi-tts` (رجل نجدي/حجازي/خليجي)، وهذا لتجربة النظام فقط.
- **الشخصية** = مقطع مرجعي + سرعة + معالجة FFmpeg (خفض النبرة، باس، صدى، ضغط ديناميكي).
- **المشاعر** = سرعة + نبرة + وقفات + طاقة (تقريبية). نبرة المقطع المرجعي هي الأقوى تأثيرًا: للحماس أعطِ مقطعًا حماسيًا، وللحزن مقطعًا حزينًا.
- **اللهجات**: النجدية أصلية (NAMAA). الحجازية/البيضاء/الخليجية تعمل بنموذج Habibi السعودي العام ومقطع مرجعي من اللهجة المطلوبة — جودتها تقريبية.

## 3) الشخصيات الجاهزة
| المعرّف | الاسم | الوصف | سرعة | معالجة |
|---|---|---|---|---|
| `narrator_deep` | الراوي السعودي العميق | سرد دافئ عميق | 0.92 | نبرة −1.5، باس +4، صدى خفيف |
| `promo_energetic` | المعلق الإعلاني الحماسي | إعلانات وعروض | 1.12 | نبرة +0.5، حدّة +2، ضغط |
| `anchor_formal` | المذيع السعودي الرسمي | نشرات رسمية (البيضاء) | 1.00 | ضغط، قصّ ترددات منخفضة |
| `narrator_female` | الراوية السعودية | سرد نسائي دافئ | 0.97 | ضغط، حدّة +1 |
| `documentary_cinematic` | الراوي الوثائقي السينمائي | مهيب بطيء | 0.88 | نبرة −1، باس +5، صدى 0.3 |

> «الراوية» تحتاج **مقطعًا نسائيًا** حتى تكون أنثوية فعلًا؛ المقطع التجريبي رجالي. ارفع مقطعًا تملك حقه.

## 4) إضافة صوتك أو صوت مصرّح به
**من الواجهة:** تبويب «الشخصيات» ← المعرّف + المقطع + النص المنطوق حرفيًا + الإقرار بالحق.
**من Claude:** `clone_voice(...)` أو `set_voice_reference(...)` مع `i_confirm_rights=true`.

شروط المقطع الجيد: متحدث واحد، بلا موسيقى/صدى، 5–8 ثوانٍ، جمل كاملة، **والنص مطابق تمامًا لما يُقال**.

**ممنوع** استنساخ صوت شخص دون إذنه، أو انتحال شخصية، أو تضليل. النظام يطلب إقرارًا لكنه لا يتحقق من صحته — المسؤولية عليك.

## 5) الاستخدام من Claude (أمثلة)
- «أنشئ تعليقًا صوتيًا سعوديًا عميقًا بأسلوب وثائقي: "في قلب الصحراء…" واحفظه MP3» → `documentary_cinematic` + `dramatic`.
- «اقرأ إعلان العرض بصوت حماسي وسرعة 1.15» → `promo_energetic` + `enthusiastic`.
- «اعرض آخر 5 توليدات» → `list_history`.
- «افحص حالة المحرك» → `engine_status`.

## 6) أدوات MCP

| `get_job` | متابعة مهمة طويلة |

## 7) السرعة
- CPU (4 أنوية، جرّبته): **~10× مدة الصوت** بـ 16 خطوة (جملة 6 ثوانٍ ≈ دقيقة). رفع الجودة: `SVS_NFE=32` (≈ ضعف الزمن).
- GPU (Colab T4): أسرع من الزمن الحقيقي عادةً (لم أقِسه هنا).
- الطلب ≤ 2000 حرف؛ الأطول قسّمه.

## 8) كتابة النص
- استخدم الفواصل والنقاط لصنع الوقفات.
- الأرقام تُكتب كلمات تلقائيًا (٢٠٢٥ ← ألفان وخمسة وعشرون)؛ للتأنيث/الإعراب الدقيق اكتبها بنفسك.
- التشكيل الخفيف مقبول؛ الإفراط فيه قد يسيء للنموذج (مُدرَّب على نص بلا تشكيل غالبًا).

## 9) الأمان
- ضع `SVS_TOKEN` (يولّده `start.sh` تلقائيًا): بدونه كل من يعرف الرابط يستطيع التوليد.
- لا تشارك رابط MCP (فيه الرمز).
- المقاطع الخاصة تُحفظ في `data/refs/` — خارج Git.

## 10) حل المشاكل
| العَرَض | الحل |
|---|---|
| `ffmpeg غير مثبت` | `sudo apt install ffmpeg` |
| بطء شديد | استخدم GPU مجاني (Colab) أو قلّل النص |
| `libcudart.so.13` | `pip install torchaudio==2.8.0` (يطابق torch 2.8.0) |
| 403 عند تنزيل النموذج | سمح لمضيفات huggingface.co و*.hf.co في شبكة بيئتك |
| صوت مشوّش | مقطع مرجعي أنظف + نص مطابق |
| لم يصل Claude إلى الخادم | الرابط العام يتغير كل تشغيل: حدّث الموصل برابط MCP الجديد |
| انقطعت جلسة Colab | افتح الدفتر واضغط ▶ من جديد (النماذج محفوظة على Drive) |
| لا يظهر رابط عام | فشل نفق Cloudflare؛ أعد التشغيل، وإلا استخدم رابط Colab الداخلي للواجهة |
