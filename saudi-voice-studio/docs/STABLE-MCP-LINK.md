# رابط MCP ثابت لا يتغير (اختياري)

## المشكلة
نفق Cloudflare المجاني (Quick Tunnel) **يعطي رابطًا جديدًا في كل تشغيل لـ Colab**. موصل Claude المحفوظ على الرابط القديم يفشل (502) بعد انتهاء الجلسة. لا يمكن لـ Colab تحديث موصلك تلقائيًا (لا يملك صلاحية حسابك).

## الحل (مجاني، مرة واحدة): Worker ثابت يحوّل إلى النفق الحالي
`https://saudi-studio.اسمك.workers.dev` ← (ثابت دائمًا) ← النفق الحالي (متغيّر). الدفتر **يسجّل** رابط النفق الجديد لدى الـ Worker تلقائيًا في كل تشغيل، فلا تحتاج لتعديل الموصل أبدًا.

### الإعداد لمرة واحدة (من الجوال ممكن)
> يتطلب **حساب Cloudflare مجانيًا** (بريد فقط، **بلا بطاقة ولا دومين**). إن لم تُرد حسابًا فتجاهل هذا الملف واستخدم الرابط المؤقت (الدفتر يطبعه ويختبره).
1. dash.cloudflare.com ← **Workers & Pages** ← **Create** ← **Create Worker** ← اسمه `saudi-studio` ← Deploy ← **Edit code** ← امسح الكود والصق محتوى `cloudflare/stable-link-worker.js` ← Deploy.
2. **Storage & Databases ← KV ← Create** (اسم `svs`) ثم في الـ Worker: **Settings ← Bindings ← Add ← KV namespace**: Variable name **`SVS_KV`** ← اختر `svs`.
3. **Settings ← Variables and Secrets ← Add**: النوع **Secret**، الاسم **`REG_SECRET`**، القيمة نص عشوائي طويل (٣٠+ حرفًا) — احفظه.
4. في Colab: أيقونة المفتاح 🔑 (Secrets) ← **Add new secret** ← الاسم **`SVS_WORKER_SECRET`** ← نفس قيمة `REG_SECRET` ← فعّل «Notebook access».
5. في خلية الدفتر: ضع رابط الـ Worker في **STABLE_WORKER_URL** (مثل `https://saudi-studio.اسمك.workers.dev`) وفعّل Drive (لحفظ الرمز الثابت).
6. شغّل الدفتر: يطبع «✅ سُجّل الرابط…» و«✅ اختبار MCP عبر الرابط الثابت نجح: N أداة» ثم **رابط MCP الثابت**. الصقه في موصل Claude **مرة واحدة**.

### ما يتغير في الأمان (قرار واعٍ)
- مع هذا الخيار **يُحفظ الرمز في `…/saudi-voice-studio/.stable_token` على Drive (صلاحية 600)** كي لا يتغير رابط الموصل. بدونه الرمز عشوائي كل تشغيل ولا يُحفظ أبدًا. لإبطاله: احذف الملف.
- الـ Worker عام لكنه لا يعمل إلا مع رمزك (يُمرَّر للخادم الذي يرفض أي رمز خاطئ)، ويقبل تسجيل رابط جديد فقط بالسر `REG_SECRET`، ويرفض أي مضيف غير `*.trycloudflare.com` (لا يصلح وكيلًا مفتوحًا).
- حدود مجانية: ١٠٠ ألف طلب/يوم في خطة Workers المجانية — أكثر من كافٍ.

## ما تحققتُ منه وما لم أتحقق منه
- ✅ منطق الـ Worker مُختبَر بـ Node (`node cloudflare/test_worker.mjs`): رفض التسجيل بلا سر/برابط غير Cloudflare، تمرير المسار والرمز للنفق الحالي، **التحوّل لنفق جديد بعد إعادة التسجيل**، و502 نظيف عند توقف الخادم.
- ❌ **لم يُجرَّب على Cloudflare الحقيقي ولا مع موصل Claude الحقيقي** — بيئتي لا تصل إلى Cloudflare ولا تملك حسابك. أول تشغيل لك هو الاختبار الفعلي، وسطر «اختبار MCP» في الدفتر يخبرك فورًا بالنجاح/الفشل.
- بدائل بلا حساب (غير مُجرَّبة هنا): تحديث الموصل يدويًا بعد كل تشغيل (لصق رابط واحد).
