# محرك الأداء الصوتي — كيف يعمل وما حدوده

## الفكرة
قبل أي توليد يُبنى **plan** (خطة أداء) لكل جملة، ويُنفَّذ حرفيًا. الخطة قابلة للتعديل بالكامل (من الواجهة أو من Claude عبر MCP).

```
النص ─► تقسيم فقرات/جمل ─► نوع النص (genre) ─► عاطفة + شدّة لكل جملة ─► النص المنطوق (قاموس/أرقام/تشكيل)
     ─► معاملات الإلقاء (سرعة، نبرة، جهارة، وقفات) ─► توليد كل جملة (ذاكرة مؤقتة) ─► معالجة/انتقالات ─► ماستر ─► MP3/WAV
```

## ما يفعله كل جزء (وما لا يفعله)
| الجزء | ما يفعله فعلًا | الحد الصادق |
|---|---|---|
| اكتشاف العاطفة | معجم عربي (فصحى + عامية سعودية) + علامات الترقيم + موضع الجملة + نوع النص؛ يشرح «لماذا» (الكلمات الدالة) | **قواعد ومعجم**، ليس فهمًا للمعنى. النص بلا كلمات دالة يخرج «محايد». صحّحه يدويًا أو دع Claude يبني الخطة |
| السرعة | تمرَّر للنموذج نفسه (تغيير مدة حقيقي) | تحت ~0.75× يبدأ النموذج بتشويه الكلمات؛ لذلك الحد الأدنى 0.75 |
| الوقفات | صمت دقيق قبل/بعد كل جملة، وأطول بين الفقرات وفي الختام | لا وقفات داخل الجملة الواحدة (النموذج يقرر إيقاعها) |
| الجهارة/التشديد | مستوى مختلف لكل جملة | — |
| النبرة | إزاحة صغيرة (±2 نغمة) بـ rubberband مع حفظ الصيغ | تعديل طبقة عامة للجملة، لا تنغيم داخلي (لا سؤال صاعد حقيقي) |
| **العاطفة الحقيقية (لون الصوت)** | **تأتي من المقطع المرجعي**: ارفع مقطعًا لكل عاطفة (حزين/حماسي…) وسيُختار تلقائيًا | بدونها، العاطفة = تشكيل إيقاع (سرعة/وقفات/جهارة/نبرة) وليست تغيير جرس الصوت |
| مضاد الرتابة | تنويع حتمي صغير للسرعة/النبرة، قوس سردي (بداية أبطأ، ختام مستقر، تنفّس بين الفقرات) | يُضبط بمنزلقين (تنويع، رسمية) |
| المحرك التعبيري (اختياري) | مفتاح `exaggeration` داخل Chatterbox يُربط بشدة العاطفة | فصحى فقط، ليس لهجة سعودية |

## عناصر التحكم
`speed` سرعة الحديث · `expressiveness` درجة التعبير · `tone_strength` قوة النبرة (نبرة/جهارة) · `pause` الوقفات · `formality` الرسمية · `variation` تنويع الإيقاع · الأسلوب (سرد/إعلان/نشرة/وثائقي/حكاية/حوار) · اللهجة. **وضع تلقائي**: النظام يقرر العاطفة؛ **وضع يدوي**: عاطفة واحدة لكل الجمل، وكل جملة تقبل التعديل. أي رقم تكتبه في «تفاصيل متقدمة» يتفوق على الحساب التلقائي.

## النطق العربي
1. تنظيف (تطويل، رموز، أرقام هندية) 2. وحدات وأرقام ← كلمات 3. **قاموس قابل للتعديل** (أسماء، علامات تجارية، اختصارات؛ مدخلاتك تتفوق) 4. اختصارات لاتينية تُهجّى حروفًا والكلمات اللاتينية المجهولة تُعلَّم لك 5. **كلمات بأكثر من نطق** (علم/ذهب/كتب/شعر…) تظهر أزرارًا لاختيار التشكيل 6. محرر «النص المنطوق» لكل جملة: ما تكتبه هو ما يُقرأ حرفيًا 7. تحويل لهجي خفيف اختياري (كلمات وظيفية قليلة فقط، معطّل افتراضيًا).

لا يوجد تشكيل آلي كامل: لا أداة مجانية بترخيص مناسب جرّبتُها بدقة موثوقة هنا.

## اللهجات
- النجدية: أصلية (NAMAA). الحجازية/البيضاء/الخليجية: Habibi السعودي العام + مقطع مرجعي، **تقريبية**.
- الفصحى التعبيرية: Chatterbox (اختياري).

## الجودة الصوتية (ماستر تكيّفي لطيف)
تنظيف ضجيج خفيف (≤9 dB) · فلتر منخفض 70Hz · إزالة الصفير (de-esser) · EQ يُختار من قياس الطيف (إن كان الصوت باهتًا فوق 4kHz رُفع قليلًا، وإن كان حادًّا/معدنيًا حول 8kHz خُفض) · ضغط ديناميكي لطيف · محدّد ذروة · جهارة −16 LUFS · تصدير MP3 256kbps @44.1kHz. ما تفعله المعالجة محدود بجودة المخرج الخام وبجودة المقطع المرجعي: **المقطع المرجعي النظيف عالي الجودة هو أكبر عامل منفرد**.

## قبل/بعد
كل نسخة تحفظ «قبل» (مخرجات النموذج كما هي، بجهارة مطابقة فقط) و«بعد» لمقارنتهما بالأذن، مع مقاييس موضوعية (جهارة، ضجيج، طاقة >4kHz، وقفات، تنوّع النبرة). المقاييس ليست حكمًا سمعيًا.
