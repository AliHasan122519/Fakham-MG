# التحسين الذكي (Smart Voice Enhancement)

زرّ واحد يجري **قبل التوليد**: تحليل المعنى ← تصحيح النطق والتشكيل ← تحديد المشاعر ← خطة إلقاء ← **مراجعتك وموافقتك** ← توليد ← مقارنة خام/محسّن.

## ما الحقيقي فيه (وما حدوده)
| الخطوة | كيف تعمل | قياس | الحد الصادق |
|---|---|---|---|
| فهم المعنى | تمثيلات جمل (`intfloat/multilingual-e5-small`، MIT) تُقارَن بجمل نموذجية لكل عاطفة، + سياق الجمل المجاورة + أدلة معجمية بوزن 30% | 44 جملة اختبار لم يرها النظام (تصنيفي أنا): **المعجم السابق 0.39 ← الدلالي 0.77** (الفرصة العشوائية 0.09) | عيّنة صغيرة بتصنيف واحد؛ ليس نموذج لغة كبيرًا؛ يخطئ في الجمل الملتبسة عاطفيًا |
| العاطفة والنوع | argmax على الاحتمالات؛ الشدّة من الثقة؛ علامات الترقيم تعدّل | — | عاطفة الجملة لا النص كله؛ راجع الخطة |
| تمييز الكلمات المتشابهة (علم/ذهب/كتب/شعر/قدر/ملك/حكم/درس/حمل…) | يقارن سياقًا محليًا (±4 كلمات) بجمل نموذجية لكل معنى | 20 جملة اختبار: **18/20 = 0.90**؛ بعتبة ثقة 0.012 ≈ 0.95 دقة مع حسم ~75% | 13 كلمة مغطاة؛ غير المحسومة تظهر لك للاختيار |
| التشكيل | تشكيل **انتقائي سياقي** للكلمات الملتبسة + قاموسك + أشكال الوقف (الحركة الأخيرة تسقط قبل الوقفة والتنوين والتاء المربوطة) | اختبارات وحدة | **لا يوجد تشكيل آلي كامل**: لم أجد أداة مجانية بترخيص واضح ودقة موثوقة على نصوص حديثة |
| الإلقاء | سرعة/نبرة/جهارة/وقفات لكل جملة + قوس سردي + ضد الرتابة | اختبارات + توليد حقيقي | العاطفة تشكيل أداء لا جرس صوت (ما لم تُضف مقاطعك العاطفية) |
| الخام الحقيقي | النص الأصلي بإلقاء محايد بلا تشكيل ولا معالجة (جهارة مطابقة) لمقارنة منصفة | تطابق التفريغ قبل/بعد | يضاعف الوقت (يمكن إيقافه) |

## هل التشكيل يغيّر نطق النموذج فعلًا؟
مفردات NAMAA/Habibi تحوي علامات التشكيل (كلها ٩)، أي أن النموذج رآها في تدريبه، لكن **لم أستطع التحقق بالاستماع** أنها تغيّر النطق بالدقة المطلوبة. لذلك التشكيل انتقائي (للكلمات الملتبسة فقط) لا شامل، وأي نص تكتبه مشكولًا يُحترم كما هو. اسمع بنفسك وقارن.

## الاستخدام
- الواجهة: «✨ التحسين الذكي» ← راجع الجمل (الأصلي / المصحَّح / المشكول، العاطفة وسببها، التفاصيل المتقدمة) ← «موافقة وتوليد».
- MCP: `smart_enhance(text, …)` يعيد خطة ونصوص الجمل الثلاثة؛ عدّلها ثم `generate_voiceover(plan_json=…)`.
- وضع **تلقائي** (يقرر النظام) أو **يدوي** (عاطفة واحدة + تعديلك لكل جملة).
