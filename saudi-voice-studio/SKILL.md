# Saudi Voice Studio (مهارة)

## متى تُستخدم
طلبات مثل: «أنشئ لي تعليقًا صوتيًا سعوديًا عميقًا بأسلوب وثائقي واحفظه MP3»، «اقرأ هذا النص بصوت مذيع رسمي»، «أنشئ شخصية صوتية جديدة»، «استنسخ صوتي من هذه العينة».

## القواعد غير القابلة للتفاوض
1. **مجاني 100%**: لا تستخدم أي API مدفوع (ElevenLabs وغيره) ولا تشغّل خدمة تتطلب بطاقة. المحرك محلي/مفتوح.
2. **لا استنساخ دون حق/إذن**: لا تستنسخ صوتًا إلا بعينة يقرّ المستخدم صراحةً أنه يملك حق استخدامها. مرّر `i_confirm_rights=true` فقط بعد إقراره في المحادثة. ارفض تقليد شخصيات عامة/مشاهير أو الخداع والانتحال.
3. **الترخيص**: أوزان NAMAA وHabibi بترخيص **CC-BY-NC-SA-4.0 (غير تجاري)**. نبّه المستخدم لذلك إن ذكر استخدامًا تجاريًا، واقترح بديلًا Apache‑2.0 (SILMA TTS، غير مدمج بعد).
4. **الصدق**: المقطع «التجريبي» ليس صوت الشخصية النهائي؛ اذكر `reference_source` و`warnings` للمستخدم. لا تدّعِ جودة لم تُختبر.

## سير العمل (عبر أدوات MCP `saudi-voice`)
1. `engine_status` — تأكد أن المحرك يعمل (CPU/GPU، FFmpeg، النماذج).
2. `list_voices` — اختر `voice` و`dialect` و`emotion` المناسبة:
   - راوٍ عميق → `narrator_deep` · إعلان حماسي → `promo_energetic` + `enthusiastic`
   - نشرة/رسمي → `anchor_formal` (`white`) · راوية → `narrator_female`
   - وثائقي سينمائي → `documentary_cinematic` + `dramatic` أو `serious`
3. `generate_voiceover(text, voice, dialect, emotion, speed)` — إن عاد `state=running` فاستعلم بـ `get_job` حتى `done`.
4. سلّم المستخدم `mp3_url` (و`wav_url` إن طلب). الروابط تتضمن الرمز السري؛ أعطها له فقط.
5. للشخصيات: `create_voice` ثم `set_voice_reference` / `clone_voice` (مع الإقرار).

## كتابة النص للحصول على أفضل نتيجة
- جمل قصيرة، ترقيم واضح (، . ؟) — الفواصل تصنع وقفات.
- الأرقام تُحوَّل لكلمات تلقائيًا؛ للنطق الدقيق اكتب الكلمات بنفسك.
- ≤ 2000 حرف للطلب الواحد؛ قسّم النصوص الطويلة.
- على المعالج (CPU) التوليد بطيء (~10× مدة الصوت)؛ أخبر المستخدم بالانتظار أو استخدم GPU مجاني (Colab).

## حدود معروفة (قلها للمستخدم عند الحاجة)
- المشاعر تقريبية (سرعة/نبرة/وقفات + نبرة المقطع المرجعي)؛ النموذج لا يملك مفتاح عاطفة حقيقيًا.
- اللهجة النجدية أصلية (NAMAA)؛ الحجازية/البيضاء/الخليجية تقريبية عبر Habibi السعودي + مقطع مرجعي مناسب.
- الشخصيات الخمس تتمايز بإعدادات إلقاء ومعالجة صوتية؛ **التنوع الحقيقي في الصوت يأتي من المقاطع المرجعية** التي يضيفها المستخدم.
